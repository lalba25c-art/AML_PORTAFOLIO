# Revisión de corrección — Versión 17

## Cambios solicitados
- Eliminado el sombreado bajo el rostro del avatar humano que producía un efecto parecido a una barba. La cara conserva el tono de piel uniforme; se mantienen ojos, nariz, boca y rasgos del diseño.
- La creación del explorador se abre automáticamente al entrar por primera vez, después de la pantalla breve de carga y antes de iniciar la historia, el mapa o las cámaras.
- Al confirmar el perfil, la expedición continúa usando ese avatar y nombre en la vista previa, el diario, las guardianas, el mundo y las interacciones.
- Si ya existe un explorador guardado en ese navegador, se conserva el perfil y no se fuerza una nueva creación en cada visita. Puede editarse desde el botón de perfil.

## Verificaciones técnicas
- Página reconstruida desde los archivos fuente del proyecto.
- Sintaxis JavaScript comprobada con Node.js.
- El archivo HTML principal actualizado en la carpeta del proyecto y la copia independiente.
- ZIP completo regenerado con fuentes, recursos, evidencias, documentación y audio.

## Nota
La apertura inicial del creador depende de que el navegador no tenga ya un perfil de explorador guardado para este proyecto. Para probar el flujo de primera visita, se puede borrar el perfil desde la opción de reinicio total del proyecto o abrirlo en un perfil limpio del navegador.
